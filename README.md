The Transmuter. 

The Transmuter is a software built for translating stl files into 5 axis tool paths for 
older CNC converted machines that have lead-screw backlash. 

The main purpose of this software is to generate g-code tool paths that respect the cutting
forces from the spindle so that traditional lead screws will always be pre-loaded and backlash
can be ignored. 

Ideally you will want to have a machine with DRO (digital read outs) on all axes since the 
software can then continually map the precision erros in the lead screws. But If you do not
have this the backlash can still be handled as a constant offset.


Install libraries: 
    setup.sh

Compile: 
    make

Run 
    ./transmuter quickTorusMilling

Examples: `torusMilling` runs the original single-stage example; `quickTorusMilling` runs coarse
roughing followed by a finer finishing stage using coarse preview defaults; `fiveAxisNormalMilling` runs the experimental normal-surface
planner. Machine kinematics checks proposed axis motion before each cut is recorded. See
[the programs](sw/controller/programs/README.md) and [the machining model](docs/machining-model.md)
for settings, force conventions, and current limits. Press **W** for workpiece coordinates or **M**
for the animated machine view. Generated paths store X/Y/Z/A/B positions, from which the
workpiece-relative tool poses are derived.
